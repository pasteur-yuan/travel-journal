# Travel Journal

以 GitHub Pages 發布的純前端靜態旅行網站。

## 專案結構

```text
.
├── index.html                  # 網站首頁
├── assets/
│   ├── css/style.css           # 共用樣式
│   ├── js/main.js              # 共用互動功能
│   └── images/                 # 圖片資源
└── countries/
    └── japan/
        ├── index.html          # 日本總覽
        ├── hokkaido/index.html # 北海道
        ├── tokyo/index.html    # 東京
        └── fukuoka/index.html  # 福岡
```

## 本機預覽

可直接用瀏覽器開啟 `index.html`，或使用任意靜態檔案伺服器預覽。

## GitHub Pages

將 repository 的 Pages Source 設定為 `main` branch 的根目錄即可發布。
