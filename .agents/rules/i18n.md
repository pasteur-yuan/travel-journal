# 多語系（i18n）規則

## 適用範圍

目前尚未提供語言切換。任何 i18n、英文版、語言按鈕、翻譯字典或可翻譯資料結構的工作都必須遵守本檔。

## 語言與路徑

- 預設語言維持繁中 `zh-Hant`，第一個新增語言是英文 `en`。
- 若要改用 `zh-TW`，必須在同一次變更更新全部模板、測試與翻譯 key；不能讓 `zh-Hant`／`zh-TW` 混作預設。
- 初期共用同一份 HTML 與翻譯字典，不為同一元件複製兩套語言 DOM，也不先建立假的 `/en/` SEO 路徑。
- 英文內容成熟並確定需要搜尋曝光時，才拆分靜態 URL，並一次補齊 `hreflang`、canonical、各語言 title 與 description。

## 翻譯資料

- header、breadcrumb、導航、分類、按鈕、tooltip、modal、空狀態及 JavaScript 動態文字必須來自同一套翻譯來源；不能只翻初始 HTML。
- 國家、地區、景點、店家、住宿與旅程資料把可翻譯名稱／描述保留為語系欄位。官方店名、日文專名與地址可保留原文，必要時另加翻譯或讀音。
- 缺 key 時回退繁中並在開發環境提示；不可顯示空白或 key 字串。

## 狀態與可及性

- 語言選擇存入 `localStorage`。只在第一次造訪時參考 `navigator.language`；不支援的語言回退 `zh-Hant`。
- 切換時同步更新 `<html lang>`、`document.title`、頁面 description 與語言控制項的 `aria-current`／`aria-pressed` 等狀態。
- 語言控制項可鍵盤操作並清楚表達目前語言。
- 每次新增語言或元件後驗證繁中、英文、缺漏回退、鍵盤操作與動態插入；不可破壞主題切換、頁內導覽或 `prefers-reduced-motion`。
